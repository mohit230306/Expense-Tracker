# Mohit Expense Tracker

A simple offline Android expense tracker.

## Features
- Add income and expenses
- Balance calculation
- Expense total
- Transaction history
- Data saved locally on the phone

## Build APK on GitHub
1. Upload these files to a new GitHub repository.
2. Open **Actions**.
3. Select **Build APK** and run the workflow.
4. After it finishes, open the workflow run and download the **Mohit-Expense-Tracker-APK** artifact.
